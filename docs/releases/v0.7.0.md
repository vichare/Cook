# Cook v0.7.0

Cook v0.7.0 adds a least-privilege administrator-assisted sign-in path for in-person users who cannot access their mailbox.

## Highlights

- Independent `account_assistance` capability with trusted-host one-time claim and revocation commands; content moderators receive no implicit access.
- Fresh Passkey and same-origin protected target inspection and OTP issuance.
- Eight-digit CSPRNG OTP, one-time reveal, HMAC-only persistence, ten-minute expiry, five attempts, replacement invalidation, atomic single use, and layered limits with `Retry-After`.
- Shared Email OTP completion for new and existing accounts, user-visible issuance/consumption notifications, and PII-minimized append-only audit.
- `admin_assisted` identity provenance blocks Gmail automatic Google linking until an ordinary mailbox OTP upgrades the identity.
- Host-only assisted sessions record method, assistant alias, and authentication time, expire within one hour, and use a centralized default-deny write policy: ordinary product testing is allowed while Passkey registration/revocation, AI/import tokens, identity changes, session management, capability claims, and administrative writes are blocked.
- Every account-assistant grant is an immutable assignment generation. Revocation atomically deletes that generation's unconsumed OTP challenges; a later claim receives a new ID and alias, so old challenges cannot revive.
- Accessible bilingual administrator confirmation, one-time reveal, assisted login continuation, user warning, and notification UX.

## Database and operations

Migration `0018_account_assistance.sql` adds provenance, assisted-session metadata, independent assignments/claims, challenge digests, persisted limits, notifications, and append-only audit. Use the commands documented in `docs/deployment.md`; never place claim codes or OTPs in logs, tickets, chat, shell history, or URLs.

## Release gates

Run the automated Rust, web, OpenAPI, and migration suites, then complete `docs/account-assistance-release-checklist.md` with real production RP/origin, Passkeys, devices, assistive technology, host claim/revoke, backup/restore, and rate-limit verification. Release only the reviewed candidate SHA.
